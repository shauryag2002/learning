## 🛠️ How to Practice Without Modifying Core Files

Whenever you tackle an exercise:
1. Open the exercise guide (e.g. [`01_two_input_sum.md`](file:///home/shaurya/Desktop/learning/android/exercises/01_two_input_sum.md)).
2. Study the problem requirements and try to write the solution in your mind or scratchpad first.
3. If you want to run it inside Android Studio:
   - You can create a temporary file (e.g. in your own test branch or scratch file).
   - Or test it using Android Studio's **Compose Preview** `@Preview` without touching your production code!
4. Check the solution code and senior tips provided in each exercise guide.
